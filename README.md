# Edukinglish • Pathfinders (CEFR B2 Web Platform)

## Archivos incluidos para subir a GitHub Pages
1. `index.html` — Interfaz completa de acceso, dashboard de módulos, videos de mini-lecciones, espacio de práctica diaria y laboratorio de conversación IA.
2. `styles.css` — Diseño limpio, minimalista y responsivo adaptado a dispositivos móviles y escritorio.
3. `app.js` — Lógica conectada directamente a tus dos archivos de Google Sheets (`Edukinglish B2 Course Syllabus & Exercise Plan` y `Edukinglish - Control de Suscriptores y Progreso`).

## Cómo subirlo a GitHub Pages en 3 pasos
1. Crea un repositorio nuevo en tu cuenta `wintoriz` (por ejemplo: `edukinglish-pathfinders-b2`).
2. Sube los archivos `index.html`, `styles.css`, `app.js` y `README.md` a la rama `main`.
3. En **Settings → Pages**, selecciona `Deploy from a branch` (`main` / `root`) y guarda. Tu plataforma quedará activa en `https://wintoriz.github.io/edukinglish-pathfinders-b2/`.
